# 旅行详情与出门演出

相册中点击照片进入同一趟旅行的详情：出发、返程或预计返程、保存的公开愿望、当时衣服、随身物品、吃食、拍照时间与可靠天气、照片和已获得的纪念品。返回按钮回到相册。正在进行或刚回家还没照片的旅行，也有入口；在外出状态中仍禁止小游戏。

旧记录按实际保存内容展示，缺失字段显示未记录。天气只读冻结的拍照场景，不拿今天的天气补历史；衣服从旅程读取，新旅程保存当时展示名称，不拿现在的穿着替代。只返回实际领取的收藏，不提前展示出发时内部预选的纪念品。

`POST /api/room-trip` 接受旅程或照片 UUID，返回白名单字段投影，支持仅有照片的旧记录。它与现有公开相册一样可公开读取，但不返回食物提供者、身份、私聊、内部理由、发送目标、密钥或天气坐标。愿望中明显涉及私人聊天、账号或链接的内容不公开展示；没有资料不编造。HTML 内容均以文本渲染，接口继续执行来源与请求大小检查，结果不缓存。

出门演出约 5 秒：从当前站位走到背包处、拿包、留条、走向房间边缘。只在已确认的生活快照由在家变成外出时触发，首次进入、刷新或过期记录不补播；减少动态效果模式只显示短提示。可跳过，切到后台停止。动画不扣饭、不改行程、不延迟真实出发或返程，跳过也不取消旅行。QQ 仍读核心的真实外出状态。

部署需同步核心、前端、`game-public-adapter.mjs` 的受限转发路径和 Cloudflare Worker 白名单；无需增加 MCP 工具或重启 DSH。更新时备份、检查会话和绘图空闲，重启核心及小屋网关，保留原配置、数据库和登录。QQ 桥接无需为本功能重启。

验证：101 项自动测试通过；独立测试环境在手机 390×844 和桌面 1280×1000 验证详情、历史穿着、返回相册、防点击穿透、拿包、跳过后仍为外出、刷新不补播。界面截图使用隔离数据，不为测试真实出游、发消息或消耗绘图额度。
