# 衣柜与回家演出

衣柜使用现有套装，不增加解锁或签到。桌面显示大预览和套装列表，手机使用紧凑预览与三列列表。选中不代表已换装：先加载当前活动需要的动作，再请求服务器确认。素材失败可重试；关闭衣柜取消尚未提交的准备；成功后下一渲染帧直接显示。保留随机换装开关和手动选择当天保留的规则。

新增服装包可提供可选的 `description`：100 字以内的可见外观描述，缺省不编造。不要写角色性格、承诺或强制台词。原有检查和安装脚本支持这个字段，仍须提供完整动作和合法素材许可。

核心公开 `wardrobe.current`（id、名称、外观），记录确认换装时间和自动/手动来源。QQ 与网页提示读取同一状态；有相关话题才自然提起，不新增每日换衣通知，不把随机选择编成精心挑选的理由。旧存档缺少时间时不声称“刚换了”。旅行照片继续使用拍照时冻结的服装参考，不重绘旧照片。

返程结算保存公开的 `travel.lastReturn`：旅程编号、地点、时间、实际纪念品；不含人物身份、私聊或内部意愿。网页观察到同次旅行从外出变为在家、且返程不足 90 秒时，播放约 6 秒的走入、放包和短暂停留。无纪念品不编造收获；首次打开、刷新或补算旧行程不补播。

演出不改变时间、库存、奖励和活动，可跳过；手动活动和换装优先，页面转到后台时停止。减少动态效果模式仅显示短提示。聊天和家具操作不锁住。

升级更新核心、套装目录与前端构建，聊天侧同步本版 `adapters/game-core-adapter.mjs`，保留本机配置和存档。新增字段向后兼容，协议仍为 v1。不要将开发配置覆盖正式配置。

验证：94 项自动测试；Edge/Playwright 在 1280×1000 和 390×844 验证预览、当前标记、无需刷新换装与刷新恢复；模拟素材失败、慢网、重复点击、准备中关闭；隔离快照验证返程放包、纪念品、跳过和不重播。没有改变正式旅程或发送 QQ 消息，也没有消耗绘图额度；真实旅行照片的光照与动作仍需在后续生成中目视检查。
