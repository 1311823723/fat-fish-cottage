# 首次进入与弱网重试

房间背景可以先于角色程序显示。独立、体积小的启动脚本会先请求同源状态接口，显示位置、天气和活动，不等待 Phaser 下载。它用带内容版本的同源经典脚本加载，兼容本地严格 CSP，不启用内联脚本权限。

文字状态已连接、角色仍在加载时会分别显示进度；长时间等待会提供重新加载按钮。主程序复用刚获取且未超过 15 秒的初始快照，随后恢复原来的 WebSocket 和五秒轮询。后台请求失败时显示重试按钮，主程序可单独重试状态，无需重新下载整个房间。启动数据只在页面内存中短暂保存，不写本地存储。

请求超时使用 AbortController 与定时器，不要求浏览器提供 AbortSignal.timeout。角色素材请求设置 20 秒超时并最多重试两次；游戏界面小图延后到打开游戏时加载。

这些改进不能保证所有网络都能访问公开托管服务。若只看到背景，优先观察“角色加载”提示；若状态连接失败，检查公开 API、隧道和本机后台。不要将 WebSocket 不通等同于小屋不可用，定时同步仍可正常使用。页面和 API 的静态缓存策略、身份验证与管理接口隔离保持原有规则。
