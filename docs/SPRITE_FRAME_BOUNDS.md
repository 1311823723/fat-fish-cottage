# 防止动作串帧

部分单行原图把相邻姿势排得过近，头发、尾巴越过固定格线。按原来格宽切片时，上一帧的一小段会出现在下一帧的另一侧；仅调整显示比例无法消除源图里已有的混入。

本次重新分离橙星奶油卫衣、蓝绒猫爪套装、浅蓝鲸鱼睡衣的 48 组动作。沿透明区域计算连续分界线，将原有像素分配到各自帧，再各加 64 像素水平透明边距。原始像素不绕回、不生成新图、不缩放，垂直位置、帧数和播放速度保持不变。服装参考图不变。更新后的网格宽度和步长一起保存，角色使用共享站立基准，透明画布变宽不会让小屋里的体型变小。

`scripts/isolate-outfit-frames.mjs` 仅处理有原始 PNG 的单行网格：

```sh
node scripts/isolate-outfit-frames.mjs <素材包目录>
node scripts/isolate-outfit-frames.mjs <素材包目录> --apply
```

第一次只预览；第二次备份到本机 `state/backups/` 后处理，失败恢复。已隔离的包再次执行不会重复加边距。多行图集或已经严重重叠、缺失的图稿需人工整理，不能把工具当作补画丢失像素的方法。位于小屋素材目录的包会同步更新套装目录，之后仍需构建产生新内容哈希。

服装检查器现在逐帧检查左右透明边缘，存在可见触边像素时拒绝安装，不能只靠整个图集四角透明判断。导出、优化和改网格后都应再检查一次，并实看完整动作，避免将检查通过误认为画面细节必然完美。

回归包括跨格像素归属、透明边距、像素不重复/丢失、垂直位置和所有已发布套装检查。浏览器通过实际 Phaser 纹理逐帧验证三套服装的 384 帧，另检查手机实际渲染。
